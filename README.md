## Topic
Hosting a Virtual Private Network in a Homelab Environnment: A Comparative Implementation of Tailscale, WireGuard, and RiseupVPN.

## What We Are Building
In this project, we are building a real Virtual Private Network (VPN) using WireGuard on a homelab machine that is reachable from the internet using port forwarding on the home router. We also test and compare two other services: Tailscale as a commercial solution and RiseupVPN as a community-based one. The goal of this project is to build a working self-hosted VPN, compare it against commercial and community alternatives, examine real-world VPN failures such as law enforcement spying, and explain how VPNs differ from Tor in protecting user privacy.
